description=[b]Tired of losing everything to one bad moment?[/b]
description=[list]
description=[*]Tired of raiding the military base, getting bitten, and realizing your only save is the one with the bite?
description=[*]Tired of a crash or a mod update breaking your world, with no older copy to go back to?
description=[*]Tired of not trying that risky plan, because if it goes wrong it costs you the whole run?
description=[/list]
description=Project Zomboid gives you [b]one save per world[/b] and overwrites it constantly. There is no "Save As", no checkpoints, no going back.
description=
description=[b]Save Slots fixes that.[/b] Make as many named saves as you want, load them, rename them and delete them, all without leaving the game.
description=
description=[img]https://i.postimg.cc/9V6kmJ71/header-banner-feature.jpg[/img]
description=
description=[list]
description=[*][b]Save As:[/b] save the game under any name, as many times as you want.
description=[*][b]Overwrite:[/b] update an existing save with the game as it is now. It asks first.
description=[*][b]Load without leaving:[/b] jump back to any save of this world and play on in your main world. The save you loaded stays as it was, so you can load it again and again.
description=[*][b]Sleep Save:[/b] each time your character falls asleep, the game is saved into a "Sleep Save" slot, replacing the one from the last sleep. Bitten the next day? Load last night. Turn it off in Options > Mods > Save Slots.
description=[*][b]Auto Backup:[/b] a backup copy is saved by itself every 30 minutes of play (10, 15, 30 or 60, or off). It keeps 2 rotating copies (1 to 3) and replaces the oldest, so a crash or power cut never costs you more than that. Paused time does not count. If zombies are chasing you or very close, it waits and saves as soon as you're clear.
description=[*][b]The game pauses while the window is open[/b] and stays paused until the save is done, so nothing can bite you while you pick a name.
description=[*][b]Rename and delete[/b] named saves right in the window.
description=[*][b]See each save at a glance:[/b] a picture of your character, name and profession, day survived, kills, infected or dead, when it was saved and how big it is.
description=[*][b]Disk use at a glance:[/b] total size of all named saves.
description=[*][b]Choose where saves go:[/b] keep named saves and Auto Backups in another folder or drive.
description=[*]English and Thai, follows the game's language setting.
description=[/list]
description=
description=[h3]Why it's useful[/h3]
description=[list]
description=[*][b]Checkpoints[/b] before raids, long drives, fights, base moves or big crafting sessions.
description=[*][b]Try things without losing your run[/b]: test a build, a route or a mod, then go back.
description=[*][b]Backups[/b] in case a crash, mod update or accidental delete breaks your main save.
description=[*][b]Branches[/b]: play the same world in different directions from one point, and jump between them.
description=[/list]
description=
description=[img]https://i.postimg.cc/b875y3tT/header-banner-design.jpg[/img]
description=[list]
description=[*][b]Only the save you choose is changed.[/b] Saving changes only that named save; loading changes only your main world. Other named saves and other worlds are only read, never changed.
description=[*][b]A failed save changes nothing.[/b] The new copy is built in a separate folder first and only swapped in when it is complete. If the disk is full or a file is locked, the old save is kept.
description=[*][b]Overwriting, loading and deleting always ask first.[/b] Only named saves of the same world can be overwritten, renamed or deleted.
description=[*][b]Your main world and the save you are playing can't be renamed or deleted[/b] from the window.
description=[*][b]Quick overwrites:[/b] saving over a save copies only the files that changed. No file is ever shared between two saves.
description=[/list]
description=
description=[img]https://i.postimg.cc/GrWfLqyX/header-banner-how-to-use.jpg[/img]
description=
description=[olist]
description=[*]In game, press [b]Esc[/b] and click [b]SAVE AS...[/b] (below Options), or press [b]F6[/b] (rebind in Options > Mods > Save Slots).
description=[*][b]To save:[/b] type a name, for example "Before the military base", and click [b]Save[/b].
description=[*][b]To overwrite:[/b] click a save in the list, then click [b]Save[/b] and confirm.
description=[*][b]To load:[/b] click a save in the list, click [b]Load[/b] and confirm. The game goes to the main menu, puts that save into your main world and opens it by itself. Anything played since then is gone, so use Save As first if you want to keep it.
description=[*][b]To rename or delete:[/b] click a named save, then [b]Rename[/b] or [b]Delete[/b].
description=[*][b]Sleep Save:[/b] just go to sleep. The game saves into "Sleep Save" as your character falls asleep, and the next sleep replaces it. Load it from the window like any other save.
description=[*][b]Auto Backup:[/b] nothing to do. Set how often and how many copies in Options > Mods > Save Slots. Auto Backups and Sleep Save are listed under "Automatic", newest first, with a clock or sleep icon. They can be loaded or deleted, but not renamed or saved over: the mod manages them.
description=[*][b]To keep saves in another folder:[/b] in Options > Mods > Save Slots, tick [b]Keep saves in another folder[/b], then click [b]Browse...[/b] to pick a folder or type its path.
description=[/olist]

description=Needs [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3619862853]ZombieBuddy[/url] (copying folders needs Java, which plain Lua mods cannot do). Build 42.21, single-player.
description=
description=[h3]Already using ZombieBuddy?[/h3]
description=If you play other ZombieBuddy mods (for example Project Viewpoint), you're set. Subscribe, enable Save Slots, and tick [b]Allow[/b] for Save Slots when the ZombieBuddy Java Mod Approval window appears. Nothing else to install.
description=
description=[h3]New to ZombieBuddy? One-time setup[/h3]
description=Subscribing to ZombieBuddy alone is not enough; its Java loader has to be installed once.
description=[olist]
description=[*]Subscribe to [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3619862853]ZombieBuddy[/url] and wait for Steam to download it.
description=[*][b]Windows:[/b] download [b]ZombieBuddyInstaller.exe[/b] from [url=https://github.com/zed-0xff/ZombieBuddy]ZombieBuddy on GitHub[/url], run it and pick [b]Normal Launch[/b]. It copies its files into the game folder and adds [b]-agentlib:zbNative --[/b] to Project Zomboid's Steam launch options. If it asks you to close Steam, do so.
description=[*][b]macOS / Linux:[/b] follow the Installation Guide on the ZombieBuddy GitHub page.
description=[*]Start the game, open [b]Mods[/b] and enable [b]ZombieBuddy[/b] and [b]Save Slots[/b]. Enable them in the main menu's Mods list, not only in the save, so Load works.
description=[*]When the [b]ZombieBuddy Java Mod Approval[/b] window appears, tick [b]Allow[/b] for Save Slots and confirm.
description=[/olist]
description=To check it works: load a save and press Esc. If you see [b]SAVE AS...[/b] below Options, you're done.
description=
description=[b]If you ever uninstall ZombieBuddy[/b], also clear [b]-agentlib:zbNative --[/b] from the launch options (Steam > right-click Project Zomboid > Properties), or the game won't start.
description=
description=[h2]Good to know[/h2]
description=[list]
description=[*]Each named save is a full copy of your world, often hundreds of MB. Delete ones you no longer need in the Save Slots window. Auto Backups take space too (2 copies by default); the footer of the window shows how much.
description=[*]After a Java update, tick [b]Allow[/b] for Save Slots again before loading a save.
description=[*]Named saves also show up in Load Game as "<world> - <name>". Opening one from there (or with Continue) works like Load: after you confirm, it is copied into your main world and the named save itself is left as it was.
description=[*][b]Saves in another folder[/b] don't show in Load Game; load them from the Save Slots window. Older saves move there when overwritten. Not inside OneDrive.
description=[*]Does not work in multiplayer; server saves are handled by the server.
description=[*]Safe to add to an existing game. Removing it leaves your named saves as normal saves.
description=[*]The Java source code is included in the mod folder (src).
description=[/list]
